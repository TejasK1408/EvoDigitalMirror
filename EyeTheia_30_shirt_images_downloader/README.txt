# EyeTheia — 30 real shirt images

This pack contains a downloader script, not the image binaries themselves.
Run `python download_30_shirts.py` on your Windows PC while connected to the
internet. It fetches 30 image files from the public CC0 clothing image
repository listed in the script and creates `shirt_images_30.zip`.

After extraction, copy the 30 image files into `EyeTheia/shopping_assets/`.

Source repository:
https://github.com/lightly-ai/dataset_clothing_images

The repository page identifies the license as CC0-1.0. Keep the
`source_manifest.txt` with the images and verify the source license if you
redistribute the collection.
